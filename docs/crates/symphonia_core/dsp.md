## Module: fft

The `fft` module implements the Fast Fourier Transform (FFT).

The complex (I)FFT in this module supports power-of-two sizes up-to 65536.



## Module: mdct

The `mdct` module implements the Modified Discrete Cosine Transform (MDCT).

The MDCT in this module is implemented in-terms of a forward FFT.
